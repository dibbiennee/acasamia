What data is processed

Anonymous usage statistics

When you open the site we record, in aggregated form: the visit and the time (Rome time zone), the page language, the type of device (phone, tablet or computer, inferred from the screen width), a general source (for example search, social, maps or direct access), any campaign named in the address, and whether the venue was open or closed at that moment.

We also record which buttons are tapped (call, WhatsApp, directions, reviews, Glovo, Instagram, Facebook), in which section of the page, which sections are reached, and whether the day and review cards are scrolled.

Everything ends up in daily counters that are not linked to a person. We do not store the IP address in the statistics, we do not create codes or device fingerprints, and we do not use cookies. The counters are kept for 400 days.

Purpose: to understand how the site is used and to improve it. Legal basis: the controller’s legitimate interest (Article 6(1)(f) GDPR).

Ahrefs analytics

The site loads the Ahrefs analytics script (Ahrefs Web Analytics), which according to Ahrefs does not use cookies. On each visit the script sends Ahrefs the page visited (path only, without address parameters), the source, the browser language, the screen size and some events such as link clicks. Ahrefs derives an approximate city-level location from the IP address and the browser, device and operating system type from the browser. To count a day’s unique visitors, Ahrefs creates a pseudonymous code from the combination of IP address, browser and a value that changes every day: according to Ahrefs, this code does not let the same visitor be recognised on different days and the IP address is not stored.

The script does not load if your browser has Do Not Track or Global Privacy Control turned on. Ahrefs does not state precise retention periods for this data.

Purpose: to understand where visitors come from and how the site is found. Legal basis: the controller’s legitimate interest (Article 6(1)(f) GDPR).

Technical hosting data

To serve the site, the hosting provider (Vercel) records technical data about each request, including the IP address, date and time, the page requested and the browser type. Content is delivered from a network of servers in several countries, so a request may be handled by the server nearest to you. The protection system limits repeated requests: to do so it uses the IP address and may temporarily reject requests from an address that exceeds the limit.

Our statistics neither read nor store this address. Purpose: to run the site and protect it from abuse. Legal basis: legitimate interest (Article 6(1)(f) GDPR). Retention: for the period set by the provider.

When you contact us

Legal basis: your request and pre-contractual measures (Article 6(1)(b) GDPR). We keep it for as long as needed to handle the request and for legal obligations. If you write on WhatsApp, the service is run by Meta, which processes data under its own privacy policy.
